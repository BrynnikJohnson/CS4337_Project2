# README - CS4337 Project 2

## Project Description
This project is the backend for a work scheduling app. The program uses input to add employees and any time constraints they have, workstations and their requirements, and any other requirements for the schedule and then creates a schedule that follows those rules.

## Files and Roles
* plan.pl: The main source code file
* devlog.md: The development log documenting each session's progress
* example-input-1-5.pl: Example input files to be used to test

## How to Run the Program
The program will create the schedule when using the command: "plan(Plan)." You will first need to load all the necessary files though. Running "['example-input-1', 'plan']." will suffice.

## Qutting
To exit the program, run "halt."
